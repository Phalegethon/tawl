# TAWL — Terminal Activity & Workload Lens

A terminal tool that makes macOS workload understandable. It shows resource pressure, the application or project consuming resources, and changes over time before presenting a technical process table. Live monitoring, recording and report commands work together. Release binaries require no compiler or additional runtime.

Measurement time, permission coverage and uncertainty are central to the product. High consumption alone is not a bottleneck or memory-leak diagnosis. Monitoring is read-only by default. A single live process belonging to the user's verified application, whether recommended or manually selected, may receive SIGTERM after an impact preview and explicit confirmation. System and infrastructure processes, automatic or bulk termination, force termination and system-setting changes are outside the scope.

Presentation uses charts, resource-specific colors and aligned comparison rows. Narrow screens prioritize summaries and charts; wider screens add an inspector for the selected application. New releases are checked in the background, but installation requires an explicit update command. Measurement data is never uploaded. English is the default interface language; Turkish is available through an explicit language setting. Project documentation is maintained in English.
